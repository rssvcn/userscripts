# userscripts
> 晴雅 Tampermonkey / Violentmonkey 油猴脚本合集

## 脚本列表
| 脚本名称 | 功能介绍 | 安装链接 |
| ---- | ---- | ---- |
| demo-script | 网页示例增强脚本 | [安装](./demo-script.user.js) |

## 使用方法
1. 先安装脚本管理器扩展：Tampermonkey（油猴）或 Violentmonkey（暴力猴）
2. 点击表格内的【安装】链接，在弹出页面确认导入脚本
3. 刷新目标网页，脚本即可生效

## 注意事项
- 脚本仅用于个人网页体验优化，请遵守对应网站的用户协议
- 网站页面结构更新后，脚本可能会失效，欢迎提交 Issue 反馈问题
