# userscripts
> My collection of Tampermonkey / Violentmonkey UserScripts

## 脚本列表
| 脚本名称 | 功能 | 安装链接 |
| ---- | ---- | ---- |
| 123pan-script | 网页示例增强脚本 | [安装](./123pan-script.user.js) |

## 使用说明
1. 先安装脚本管理器扩展：Tampermonkey / Violentmonkey
2. 点击表格内的【安装】链接，在弹窗中确认导入脚本
3. 刷新目标网页，脚本即可生效

## 注意事项
- 脚本仅用于个人网页体验优化，请遵守对应网站服务条款
- 网站页面结构更新后，脚本可能失效，欢迎提交issue反馈问题
